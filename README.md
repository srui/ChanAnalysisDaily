线上访问：**https://srui.github.io/ChanAnalysisDaily/**

## 每日页面固定板块

TL;DR → 时间线 → 复盘（二值打分 + 打脸记录）→ 五级递归联立（周→日→4h→30m→5m）→ 🚨币圈大事件 → 📰消息面 → 📅本周金融日历 → 🏛九段升级检查 → 🗺趋势全景地图 → 八币速览 → 三演化 → 预案表（含 271 入场法）

## 纪律

- 快照冻结：每页锚定生成时刻，次日不变形
- 影线不算突破、针不算跌破——收盘口径唯一
- 背驰给减仓信号，不给反手信号
- 概率是主观估计必须标注；复盘打脸不遮掩

仅供个人学习研究，不构成投资建议。
