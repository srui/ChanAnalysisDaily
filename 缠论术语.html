1基础结构
分型Fractal基础
连续 3 根K线构成的最小转折单元。中间一根最高=顶分型(▲)，中间最低=底分型(▽)。是判断"笔"端点的基础。
🎯 实战意义
顶分型=潜在卖点，底分型=潜在买点。但单独分型不构成买卖点，需结合趋势和中枢。
🛠 工具应用
实时分析K线图用▲▽标注分型；AI分析用分型找压力支撑
笔Stroke / Bi基础
相邻的顶分型与底分型之间的走势。笔是缠论最小的完整走势单元，向上笔(底→顶)或向下笔(顶→底)。
🎯 实战意义
笔的方向=短期趋势方向。多笔组合形成线段和中枢。
🛠 工具应用
实时分析通过分型序列自动识别"笔"，用于判断当前走势方向
线段Segment基础
至少由 3 笔组成的走势。线段是比笔高一级别的结构，3笔以上的线段才可能包含中枢。
一个上涨线段(至少3笔): ▲ ─╮ ╭─ ▲ ← 第3笔(向上) ╲ 第2笔 ╱ ╲ (向下) ╱ ▲ ──╲──────────╱ ╲ ╱ ▽─────▽ ← 第1笔端点 第1笔(向上)
🎯 实战意义
线段结束=走势转折。线段内部的3笔重叠构成中枢。
🛠 工具应用
本工具暂未单独画线段，但中枢识别基于线段的3笔结构
2走势结构
中枢Zhongshu / Pivot Zone核心
至少 3 个连续次级别走势类型的价格重叠区间。中枢有上沿ZG和下沿ZD，代表多空博弈的平衡区。中枢是缠论最重要的概念。
🎯 实战意义
① 价格在中枢内=震荡(观望) ② 突破ZG=转强 ③ 跌破ZD=转弱 ④ 三类买卖点都围绕中枢
🛠 工具应用
实时分析自动识别中枢并画紫色矩形+ZG/ZD虚线
走势类型Trend / Range核心
走势类型严格只有三种：盘整=只含1个中枢；上涨趋势=2个以上依次上移的同级别中枢；下跌趋势=镜像。「单边」不是第四种——它是趋势的极端形态（回调极浅、本级别中枢来不及形成，常见于消息驱动），在大级别看往往只是一笔。
三种走势类型(按结构定义,不按涨跌幅): ① 盘整: ┌─中枢─┐ 只含1个中枢,方向未选 └──────┘ ② 趋势: 中枢①↑ 中枢②↑ 中枢③↑ ≥2个同级别中枢"依次同向移动" (依次上移=上涨趋势;依次下移=下跌趋势) ③ 单边(极端趋势,非独立类型): ╱╱╱╱ 几乎不回头 中枢形成速度跟不上价格推进 本级别中枢缺失/只在次级别 → 大级别看往往只是一笔 ⚠️ 趋势不只数中枢个数: 两个中枢必须依次移动且区间不重叠 两中枢若重叠 = 中枢扩展 = 升级成更大级别的盘整, 不是趋势 ⚠️ 盘整的定义是结构性的"1个中枢",不是幅度——宽幅震荡只要一个中枢也是盘整 🔑 重点看级别: 同一段行情, 30m是趋势(3个中枢上移), 4h可能只是"1个中枢后的一笔"
📊 真实例子(ETH/BTC)
盘整：ETH 8/10–8/17 中枢 1,862~1,925 横5段——一个中枢、方向未选，8/17 向上突破才完成（图见下方"走势终完美"例1）。
趋势 vs 级别（重点）：当前 ETH 8/02 以来的上涨，在 30m 级别已是趋势（3个中枢依次上移）；但在 4h 级别还不算趋势——只有 1,862~1,925 一个中枢＋突破延伸，第二个 4h 中枢还没长出来。同一段行情，两个级别两种结论——这就是"重点看级别"。
单边：BTC 8/19 64,131→70,450，几根4h大阳直接推（特朗普政策消息驱动），30m中枢极小、4h级别只算一笔。单边的本质＝价格推进速度＞中枢形成速度——最强，但由"走势终完美"可知也最不可持续。
🎯 实战意义
趋势中顺势操作，盘整中观望或区间高抛低吸；单边=趋势最强段，只顺势、绝不逆势
🛠 工具应用
K线分析仪表盘显示"4H趋势：上涨/下跌/震荡"；位置分析同时看30m/4h两级中枢数量——级别对照的日常练习
级别Level / Timeframe核心
走势的"刻度"。常用级别：1分/5分/15分/30分/1小时/4小时/日线/周线。高级别看方向，低级别找点位。
级别从大到小: 周线 > 日线 > 4H > 1H > 30分 > 15分 > 5分 > 1分 └─── 趋势周期(看方向) ───┘ └ 交易周期(找点位) ┘ 本工具的4种周期联立: 5分/30分(超短) · 15分/1H(短线) · 1H/4H(波段★) · 4H/日线(中波段★)
🎯 实战意义
不同级别看到不同的结构。大级别定方向，小级别精确买卖
🛠 工具应用
实时分析支持4种周期联立，趋势周期+交易周期双层判断
走势终完美Trend Perfection两大原理之一
缠论两大基本原理之一：任何级别的任何走势类型，终要完成。上涨终会结束、下跌终会结束、盘整终会选择方向——没有走不完的行情。完成后的走势必然转化为其他走势类型（走势的连接），如此循环不息。
三种走势类型的"完美(完成)"方式: 上涨: 中枢① ↑ 中枢② ↑ ... 背驰 ──→ 完成 → 转化为盘整或下跌 下跌: 中枢① ↓ 中枢② ↓ ... 背驰 ──→ 完成 → 转化为盘整或上涨 盘整: ┌─ 中枢 ─┐ 三类买卖点选方向 ──→ 完成 → 转化为趋势 两层含义: ① 必然性: 走势一定会走完("终") —— 市场唯一100%的承诺 ② 可识别: 完成时必然给出信号(背驰/三类买卖点) —— 技术分析的立足点 ⚠️ "终"不承诺"何时": 完美是必然的,时点是未知的 这就是为什么: 永远有机会(不追), 完成有证据(等信号), 不预测时间(不赌)
📊 三个真实例子(本工具数据)
例1 · 盘整终完美：ETH 8/10–8/17 在 1,802–1,947 大中枢里横了 7 天（20段延伸），8/17 放量突破中枢上沿——盘整走势完成，转化为上涨。看它横盘时多像"永远不涨"，但"终完美"保证了它必然选方向。
例2 · 上涨的完成需要证据：ETH 当前 1,868→2,549 的上涨，动能 240%（未衰竭）——走势还没完美，所以 8/21 顶 2,449 的 30m 背驰全部被吸收。哪天 4h 红柱面积萎缩+DIF 走高转走低，才是这个上涨"完美"的证据，在那之前它完美地碾过一切逆势单（包括 8/19 那笔 -41.83 的空单）。
例3 · 下跌同样终完美：8/2–8/12 ETH 的下跌段最终在 1,862 见底——不是有人预测到的，是下跌走势自己走完了（底背驰+底分型确认）。「不预测，等走势把它自己走完」。

同级别分解Same-Level Decomposition走势结构
把任意级别的走势唯一分解成本级别走势类型（上涨/下跌/盘整）的连接。分解单位是本级别走势类型：一个中枢=盘整段，两个同向不重叠中枢=趋势段；相邻两段不能同向（同向必须合并）；每段走完（终完美）才能切换到下一段。
同级别分解 = 把走势切成一段段的"类型连接": ┌─上涨─┐┌─盘整─┐┌─上涨─┐┌─下跌─┐┌─盘整─┐ ╱ ╲╱ 震荡 ╲╱ ╲╲ ╱╲ 震荡 ╱ ← 每段都是完成的走势类型 三条规则: ① 单位 = 本级别走势类型(1个中枢=盘整; 2个同向不重叠中枢=趋势) ② 相邻两段不同向: 上涨+上涨必须合并成一段 ③ 每段终完美后才切换 → 分解是"事后可证、当下可跟"的 用途1 定位: 当下处在第几段、什么类型里 → 决定策略 用途2 比背驰: 背驰只在同级别两段之间比较才有效 用途3 机械化: 每段完成后切换操作模式(趋势段顺势/盘整段高抛低吸)

3力度判断（背驰）
趋势背驰Trend Divergence一类买卖点核心
同一趋势中，价格创新高/低，但 MACD 柱子面积缩小 → 力度衰竭 → 即将反转。背驰是一类买卖点的判定依据。
🎯 实战意义
顶背驰=见顶预警(做空)，底背驰=见底预警(做多)。这是抄顶/抄底的核心信号
🛠 工具应用
实时分析自动检测，MACD副图标出两段面积阴影+顶连线+面积数值
盘整背驰Range Divergence背驰
盘整(震荡)区间内的背驰。当价格在中枢内再次触及边界但MACD面积缩小，预示将向中枢另一端运动。
盘整背驰(中枢内): ZG ════════╤════════╤════ ← 触及上沿但力度弱 │ ↗ ↗ ↗ │ (盘整背驰→回落) ZD ════════╧════════╧════ vs 趋势背驰: 盘整背驰在区间内,趋势背驰在同向趋势末端
🎯 实战意义
盘整背驰用于中枢内的"高抛低吸"，预判价格回到中枢中部
🛠 工具应用
本工具暂只识别趋势背驰，盘整背驰需人工结合中枢判断
MACD柱子面积MACD Histogram Area力度量化
一段走势内同向MACD柱子高度之和。缠论用它量化走势的"能量/力度"，比单看DIF峰值更准确。
红柱面积 = ∑(每根红柱的高度) 代表上涨力度 例: 前段上涨(10根大红柱) 后段上涨(8根小红柱) ████████████████ area=850 ███████ area=420 850 → 420 (缩小49%) = 力度衰竭 = 背驰 为什么用面积不用DIF? 面积是"能量积分",更稳定 单根异常柱子会干扰DIF峰值,但面积抗干扰
🎯 实战意义
面积量化了走势力度，是背驰判定的客观依据
🛠 工具应用
背驰检测自动计算两段面积，MACD副图用阴影标注对比
级别传导Level Transmission核心理论
小级别背驰只承诺本级别的回拉（至少回到本级别最后一个中枢），对大级别的影响要靠后续走势"生长"出来。三种结局：①被大级别吸收（只是大级别一笔）、②引起大级别盘整（长出新中枢）、③传导成大级别反转（最少见，需要级别共振）。
30m顶背驰发生后的三种命运(概率从高到低): ①被吸收(最常见) ②引起大级别盘整 ③大级别反转(最少见) 4h: ╱╲╱↗╱╱↗ 继续新高 4h: ╱╲╱┌──────┐╱ 4h: ╱╲╱┌──────┐ 30m: ╱╲╱(背驰)╱↗ 30m: ╱╲(背驰)╲▂▂▂▂▂╱ 30m: ╱╲(背驰)╲▂▂▂└╲ 回调=4h的一笔 长出4h新中枢=盘整 盘整后向下+4h自身背驰 背驰承诺的只有: 回到本级别最后中枢。大级别怎么消化它,要等它自己走出来 反过来看=区间套: 大级别背驰可下钻找精确点(大定小),小级别背驰向上会被稀释(小不定大)
🎯 实战意义
30m背驰≠4h反转：只用来"不追多/收紧止损"，从不当反向开仓依据；趋势终结必须等大级别自己背驰

位置分析看4h动能对比；末期检查表要求"4h背驰"而非"30m背驰"作为趋势终结标志 · 下方是真实K线案例↓

4三类买卖点（核心）
一类买卖点1B / 1S · Type-1性价比最高
趋势背驰后的反转点。一类买点(1B)=下跌趋势末端背驰见底；一类卖点(1S)=上涨趋势末端背驰见顶。是抄顶/抄底的位置。
🎯 实战意义
最精准的抄顶抄底位置，盈亏比最大，但需要等趋势背驰确认
🛠 工具应用
实时分析检测到背驰会提示"一类买卖点预警"
二类买卖点2B / 2S · Type-2最常用
一类买卖点后，价格回调/反弹不破前低/前高的点位。确认趋势反转，风险较低，是实战最常用的买卖点。
🎯 实战意义
反转确认后的入场点，比一类买卖点安全，盈亏比依然好
🛠 工具应用
实时分析"回调到位可做多"即二类买点逻辑
三类买卖点3B / 3S · Type-3最强趋势
中枢被突破后，价格回踩不进入中枢的点位。代表最强趋势确认，往往开启主升/主跌段。
🎯 实战意义
最强趋势确认点，往往是一波大行情的起点，单笔爆发力最大
🛠 工具应用
实时分析配合中枢，识别"突破回踩"的三类买卖点
5实战应用
区间套Interval Nesting高级技巧
用大级别找背驰区间 → 小级别精确定位买卖点。如同用放大镜逐级缩小，把买卖点锁定到极精确的位置。
日线级别: 发现背驰区间(10000-11000) ↓ 缩小到4H 4H级别: 背驰区间(10200-10500) ↓ 缩小到1H 1H级别: 精确买点(10300-10350) ← 实际进场 大级别定区域,小级别定点位,逐级精确
🎯 实战意义
区间套能把进场点精确到很小范围，最大化盈亏比
🛠 工具应用
实时分析的双周期联立就是区间套思想的简化应用
周期联立Multi-Timeframe Alignment本工具核心
趋势周期(大级别)定方向 + 交易周期(小级别)找买卖点。顺大势逆小势——只在两个周期方向一致(共振)时交易。
4H趋势(下跌) + 1H反弹到顶 = 二类卖点做空 ✓ ↓ 大级别方向 ↓ 小级别卖点 下跌 反弹受阻 (做空) (确认做空) → 方向一致 → 共振! 最佳做空时机 4H趋势(下跌) + 1H回调到底 = 逆势不做 ✗ (做空) (可做多) → 方向相反 → 放弃(顺大势原则)
🎯 实战意义

顺势 / 逆势Trend-Following / Counter-Trend交易原则
顺势=交易方向与大级别趋势一致；逆势=相反。缠论铁律：顺大势逆小势——只做与大级别趋势同向的单。
4H下跌趋势中: ✅ 顺势: 做空(等反弹受阻) → 顺大势 ❌ 逆势: 做多(回调抄底) → 逆大势,放弃 4H上涨趋势中: ✅ 顺势: 做多(等回调止跌) → 顺大势 ❌ 逆势: 做空(反弹抓顶) → 逆大势,放弃 你之前26笔复盘:19笔顺势全盈利,3笔逆势小亏
🎯 实战意义
顺势交易胜率最高。逆势单即使短期盈利，长期必亏
🛠 工具应用
实时分析"共振/背离"标签；交易日志缠论标签可标"顺势/逆势"
强平 / 爆仓Liquidation风险
保证金不足以维持持仓时，交易所强制平仓。杠杆越高，强平距离越近。50x约反向1.2%就爆仓。
强平距离 ≈ 1/杠杆 × (1-维持保证金率) 杠杆 反向多少强平 评价 5x ~12% ○ 最安全 10x ~6% ✓ 推荐 15x ~4% ✓ 可接受 20x ~3% △ 上限 50x ~1.2% ✗ 极危险(止损前就爆) 本工具:仓位计算器自动算爆仓价和安全垫
🎯 实战意义
爆仓=血本无归。止损必须在强平价之前，且留足安全垫
🛠 工具应用
仓位计算器显示爆仓价+安全垫+杠杆对照表
